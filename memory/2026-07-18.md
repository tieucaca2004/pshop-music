- **Current (12:47) state:** 
  - Local file → **CORRECT** plain text (50 bytes): `google-site-verification: google4da8ca6ec5109217.html`
  - Deployed file → **WRONG**: HTML with `<meta name="google-site-verification" content="4da8ca6ec5109217" />` (131 bytes, Content-Type: text/html)
  - Deploy pending — needs fresh Netlify auth token

### Critical Lesson: Stop Guessing, Get Originals
- Multiple (8+) session loops where agent repeated same troubleshooting without making progress
- Founder explicitly said "Stop guessing. Download the ORIGINAL file from GSC. Deploy AS-IS. Byte-for-byte" (#648)
- Agent could NOT download from GSC via Chrome MCP (Material Design button not interactive)
- Founder shared the original file content manually (#660)
- **Lesson:** When GSC verification fails with "wrong content", do NOT hand-write files — get the actual Google-generated original file from the GSC dialog
