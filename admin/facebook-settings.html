Kết nối Facebook

Để đăng bài Facebook tự động, PSH Platform cần được cấp quyền kết nối với tài khoản Facebook của bạn.

Hệ thống SẼ:

  • Xác thực tài khoản Facebook của bạn.
  • Lấy danh sách Fanpage bạn đang quản lý.
  • Tự động lấy các API Token cần thiết.
  • Cho phép AI đăng bài — CHỈ sau khi bạn duyệt từng bài.

Hệ thống SẼ KHÔNG:

  • Đọc tin nhắn Messenger.
  • Đọc hội thoại riêng tư.
  • Truy cập thông tin ngoài phạm vi quyền đã cấp.

Bạn có thể ngắt kết nối bất kỳ lúc nào.
